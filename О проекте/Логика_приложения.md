### Экран блокировки (появляется при попытке открыть платный блок)

```

│                         │

│                         │
│ Для оплаты:             │

│ 3. Прикрепите скриншот   │
│                         │
│ [Оплатить в Telegram]   │

```

### Генерация DeviceID

**При первом запуске:**
```javascript
const randomPart = Math.random().toString(36).substring(2, 7).toUpperCase();
const deviceID = 'Kiip_' + randomPart; // Kiip_X7R2A9Z
localStorage.setItem('kiip_user_id', deviceID);
```

**Хранение:**
- Ключ: `kiip_user_id`
- Значение: `Kiip_X7R2A9Z`
- Доступен глобально: `const userID = localStorage.getItem('kiip_user_id');`

### Интеграция с Telegram

**При нажатии [Оплатить в Telegram]:**

1. **Автоматически формируется текст:**
   ```
   Здравствуйте! Хочу оплатить доступ к KIIP Easy.
   Мой ID: Kiip_X7R2A9Z
   Прикрепляю скриншот оплаты на 9,900₩
   ```

2. **Текст копируется в буфер обмена**

3. **Открывается Telegram** (или ссылка на ваш Telegram)

4. **Пользователь:**
   - Вставляет текст (Ctrl+V)
   - Прикрепляет скриншот оплаты
   - Отправляет

### Процесс активации

**С вашей стороны:**
1. Получили скриншот + ID пользователя
2. Проверили оплату
3. Сгенерировали ключ: `Kiip_X7R2A9Z-KIIP90`
4. Отправили ключ пользователю

**С стороны пользователя:**
1. Получил ключ в Telegram
2. Открыл приложение
3. Ввел ключ в поле активации
4. Доступ разблокирован

### Привязка ключа к DeviceID

**Ключ работает ТОЛЬКО на том устройстве где сгенерировали:**

```javascript
// Проверка ключа
const savedKey = localStorage.getItem('kiip_key');
const deviceID = localStorage.getItem('kiip_user_id');

// Ключ должен содержать DeviceID
if (savedKey && savedKey.includes(deviceID)) {
  // Доступ разрешен
} else {
  // Показать экран блокировки
}
```

**Формат ключа:** `Kiip_X7R2A9Z-KIIP90`
- Первая часть: DeviceID
- Вторая часть: код доступа

**Ограничения:**
- Ключ нельзя передать другу (не подойдет к другому DeviceID)
- Смена телефона → нужен новый ключ
- Нельзя использовать на 2 устройствах одновременно

### Экран ввода ключа

**Доступен:**
- Из экрана блокировки (кнопка "У меня есть ключ")
- Или сразу при получении ключа в Telegram (deep link)

```
┌─────────────────────────┐
│ 🔑 Активация доступа     │
│                         │
│ Введите ключ:            │
│ ┌─────────────────────┐ │
│ │ Kiip_X7R2A9Z-KIIP90 │ │ ← поле ввода
│ └─────────────────────┘ │
│                         │
│ [Активировать]          │
│                         │
│ Нет ключа?              │
│ [Оплатить 9,900₩]       │
└─────────────────────────┘
```

**Логика активации:**
1. Пользователь вводит ключ
2. Приложение проверяет: содержит ли ключ DeviceID пользователя
3. Если да → сохраняет в localStorage: `kiip_key`
4. Перезагружает приложение → открывает все блоки

**Проверка:**
```javascript
function checkAccess() {
  const key = localStorage.getItem('kiip_key');
  const deviceID = localStorage.getItem('kiip_user_id');

  if (key && key.includes(deviceID)) {
    return true;  // Доступ разрешен
  }
  return false;  // Показать экран блокировки
}
```

## Стр2.1 — Лента вопросов

### Контейнер вопроса (стандартизированный компонент)
Все ~450 вопросов используют **одинаковую структуру контейнера**:

```
┌─────────────────────┐
│ 🟦 Полоса (статус)   │ ◄── серая/зеленая/красная
│ ❓ Вопрос (KO)       │
│ ○ Вар1             │ ◄── вертикально, друг за другом
│ ○ Вар2             │
│ ○ Вар3             │
│ ○ Вар4             │
│ 🟠 Разбор задания   │ ◄── кнопка появляется после ответа
└─────────────────────┘
   ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
     легкая тень
```

**Цвет контейнера = цвету блока:**
- Блок 1 → голубой контейнер
- Блок 2 → желтый контейнер
- Блок 3 → зеленый контейнер
- Блок 4 → розовый контейнер

**Стиль:** легкая тень вокруг (эффект листа бумаги)

**Адаптивный размер:**
- Контейнер **растягивается автоматически** по контенту
- Длина вопроса: 1-4 строки → контейнер подстраивается
- Длина вариантов: могут быть длинными → контейнер расширяется
- Листок разбора: тоже растягивается
- **Нет фиксированной высоты** — только `min-height`

### Начальное состояние
- Все полоски серые (неотвеченные)
- Прогресс: `0🟢0🔴 | 18`

### После выбора ответа
- Полоска окрашивается: 🟢правильно / 🔴неправильно
- Появляется кнопка **"Разбор задачи"** под вариантами ответов (всегда)
- Прогресс обновляется: правильные|неправильные|общее

### Прогресс-бар
Формат: `5🟢2🔴 | 18`
- Слева зеленый — количество правильных
- Справа красный — количество неправильных
- После общего — общее количество вопросов

### После нажатия "Разбор задачи"
- Контейнер **растягивается вниз**
- Листок с разбором **выезжает изнутри** контейнера (slide down)
- Блок с вопросом плавно скроллится вверх
- Разбор занимает место до конца контейнера
- Сверху справа: **крестик (×)** для закрытия
- Результат: вопрос и разбор видны одновременно
- **Внизу листика:** номер вопроса мелким шрифтом (`#64`)

**Анимация:** листик feels часть контейнера, не наложен сверху

**Нумерация вопросов:**
- Порядковая нумерация внутри каждого блока (начинается с #1)
- Блок 1: #1-100, Блок 2: #1-125, и т.д.
- Номер находится на листике разбора, внизу, мелким шрифтом
- Используется для отчета об ошибках: "в #64 ошибка в вопросе"

### После последнего (18-го) вопроса
- Внизу появляется кнопка **"Результат"**
- Кнопка "Разбор задачи" работает как обычно

## Стр5 — Экран результатов

### Контент

- Итоговый счет: правильные (зеленая полоса) / неправильные (красная полоса)

## Ключевые UX-решения

1. **Стандартизированный контейнер вопроса** — один компонент для всех ~450 вопросов
2. **Цветовая кодировка** — контейнеры наследуют цвет блока (всегда понятно где находишься)
3. **Разбор после каждого ответа** — не ждёшь конца теста
4. **Разбор всегда доступен** — пользователь выбирает читать или нет
5. **Выезжающий листок** — разбор появляется изнутри контейнера (естественная физика)
6. **Легкая тень** — эффект листа бумаги (единство стиля "блокнот")
7. **Автопрокрутка при разборе** — вопрос и разбор на одном экране
8. **DeviceID с префиксом** — Kiip_X7R2A9Z (брендинг + уникальность)
9. **Привязка ключа к устройству** — ключ нельзя передать другу
10. **Оплата через Telegram** — авто-формирование сообщения, просто для пользователя
11. **Freemium** — первый блок бесплатно, остальные по ключу

## Архитектура MVP (бесплатно, без сервера)

### Технический стек
| Компонент | Решение | Почему |
|-----------|---------|--------|
| Тип приложения | **PWA** | Обход сторов, мгновенные обновления |
| Контент (вопросы) | **JSON файлы** | Нативный для JS, быстро работает |
| Прогресс пользователя | **localStorage** | Встроен в браузер, бесплатно, офлайн |
| Бэкенд/сервер | **Не нужен** | Экономия денег |
| Синхронизация устройств | **Нет** | Если другое устройство — прогресс обнуляется |

### Структура данных (localStorage)
```javascript
{
  // Идентификация устройства
  "kiip_user_id": "Kiip_X7R2A9Z",

  // Ключ активации (если оплачено)
  "kiip_key": "Kiip_X7R2A9Z-KIIP90",

  // Прогресс по блокам
  "progress": {
    "block1": {
      "answered": [1,3,5],          // отвеченные вопросы
      "correct": [1,5],             // правильные
      "wrong": [3]                  // неправильные
    }
  }
}
```
